    台本编辑器（当前版）¶

    2026-11-12：台本已移入独立 GodotLevelEditor窗口的“台本”页，保存和读取统一使用配表/dialogues.xlsx；旧 CSV 仅保留在 resources/narrative/legacy/。当前窗口、配表与任务操作见 统一说明。下文记录此前 V2 的层级与交互，CSV 保存／导出描述已被当前 XLSX 工作流替代。

    台本与任务编辑器 V2¶

    2026-11-12。顶部 台本与任务 → 台本编辑器。

    界面和结构¶

    对话组                 Comments               对话 ID  | NPC 姓名 | 对话内容
任务 A                 1 进入                 00001    | 接待员   | ……
                       2 测试                 00002    | 玩家     | ……
                                                              保存对白  导出对白

    对话组用于整理同一任务／场景的文本。Comment 是一次触发后连续播放的最小段落，内部对白按表格顺序自动往下播，到当前 comment 结束即停止，不进入下一个 comment。

    • 左侧点对话组，中间点 comment，右侧显示该 comment 的完整对白表。
    • 主表只保留 ID、NPC 姓名和内容。双击一行打开详情，可编辑完整多行文本、NPC、颜色、台本类型及显示秒数。0 秒按字数自动估算，正数为指定秒数。
    • NPC 新名字自动配色，同名匹配并共用颜色；可从已有 NPC 列表选择。
    • 搜索只筛选当前表格，不影响保存或导出的范围。
    • 新对白自动分配 00001 形式的 ID。移动、重命名、改内容不改 ID；复制会生成新 ID；撤销后编号不倒退复用。

    右键菜单¶

    位置 功能
    对话组 新建、重命名、复制整组、删除整组、上下移动、复制 ID
    Comments 新建、重命名、复制段落、删除段落、上下移动、复制触发 ID
    对白行 新建、插入到之前／之后、编辑详情、复制、删除、上下移动、复制 ID

    删除包含子级的内容时会显示确认，所有增删、编辑和排序支持撤销／重做。右键空白处可以新建对应层级内容。

    保存和导出¶

    • 保存对白：保存 .dialogue.tres 编辑源，保留全部分组、顺序、颜色和编号计数。
    • 导出对白：将全部对话组和 comments 导出为 UTF-8 CSV 配表，游戏从这个 CSV 读取台词。成功导出也会更新已有编辑源。
    • 保存但未导出时显示“待导出 CSV”，防止误以为游戏内容已经更新。
    • “打开对白”支持编辑源和 CSV。打开 CSV 后可另存编辑源。
    • CSV 支持中文、逗号、引号和多行内容；ID 按字符串读取，保留前导零。表头和版本错误、重复 ID、错误时长或不一致分组会拒绝载入。

    默认样例：resources/narrative/reception.dialogue.tres 与 resources/narrative/reception.dialogue.csv。旧版二级台本会迁移为“对话组 → comment → 对白”，原来组 ID 作为新 comment 的 ID 保留，原单句 ID 同样保留，避免任务引用失效。迁移后保存时写入 V2；未知版本不覆盖。

    接任务编辑器¶

    1. 保存并导出对白。
    2. 右键目标 comment，点“复制 ID”。
    3. 任务图的 ShowDialog 播放 comment 填这个 ID；“对话完成时 Trigger”也填相同 comment ID，连接任务完成节点。需要检测单句结束时，可填写该句 ID。
    4. 任务页点“使用台本页当前库”，绑定当前源文件对应的 CSV；或在任务资源检查器设置 dialogue_csv。
    5. ShowDialog 的继续输出表示开始播放；只有完成触发表示整段播完。空 comment、无效 ID 或播放忙碌会失败。

    运行中的字幕仍只显示底部的“NPC：内容”，自动切下一句。F / Enter 可提前推进当前句，画面不显示类型、句数或继续按钮。对话结束恢复交谈前的界面显隐和暂停状态。

    游戏导出时，插件会把任务资源所引用的 CSV 加入包内；CSV 设置为原始文件，避免被 Godot 当作翻译表导入。

    试玩与验证¶

    默认入口由白盒编辑器聊天维护。对话专项样例独立放在 tools/narrative/session_fixture.tscn，任务页可点“打开对话试玩”，再按 F6；进入房间、走近接待员按 F，之后自动播放当前 comment 并完成任务。测试不写正式存档。
