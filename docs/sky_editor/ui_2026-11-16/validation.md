## 已完成的调整

- 参数分为天空背景、时间与太阳、环境光、云层、雾五页；每页独立滚动，预设名称、保存状态和预览／绑定操作常驻。
- 统一参数区宽度，数值输入、颜色色块与开关保持紧凑；滑块显示完整轨道及蓝色位置。字体、缩放与其他编辑器样式沿用套件设置。
- 时刻改为 HH:MM 与分钟滑块；自动角度在蓝底结果区域显示，隐藏旧的手动值。切换手动时沿用实际太阳位置，并支持整组撤销。
- 颜色可选色或输入 #RRGGBB；云量和雾浓度显示百分比；不适用参数收起并保留数据。HDRI／模板云层页说明来源。
- 数值显示精度与箭头增量分离，1200m／900m／1.08 等值不再被步长显示成 1201m／901m／1.1。
- 底部优先显示关卡中文名及已绑定环境，草稿未保存时先保存再绑定；保留 HDRI 导入期间的锁定及请求归属保护。
- 用词采用实际功能名称，没有重命名已有预设、关卡或稳定 ID。
