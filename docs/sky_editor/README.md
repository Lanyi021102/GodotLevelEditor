# 天空编辑器 V1

2026-11-15。独立 GodotLevelEditor 窗口新增“天空”入口，关卡继续在 Godot 原生 3D 视口编辑。

## 使用

1. 打开天空，选择内置预设，可复制、新建、编辑、撤销和重做。内置模板的“保存预设”会进入另存为，自定义预设保存到 `resources/sky_presets/custom/`。
2. 打开一个大世界关卡，点“临时预览”。参数修改实时反映到原生视口；“中性检查”和“对比已绑定”用于原位比较，“临时预览”切回草稿，“结束预览”恢复关卡环境。关闭工具窗口、切换场景或开始试玩也结束预览。
3. 保存预设后点“绑定到当前关卡”，再保存场景。也可在“关卡 → 编辑关卡信息 → 天空预设”选择并保存；该入口保存绑定到关卡场景。关卡详情显示当前绑定名称。

原生“保存全部”会保存当前草稿；新建或内置模板的草稿会自动另存到自定义目录，不自动绑定关卡。

旧关卡默认显示“现有光照”，不自动改写；新关卡默认绑定 V2 光照模板。可以在关卡信息中选择“现有光照”解除绑定。共享预设修改后会影响引用它的关卡；希望独立调整时先复制并另存。左侧显示已保存的引用关卡。

## 参数与范围

- 程序天空：天顶、地平线、下半球颜色，太阳圆盘，静态云层；云量、云层高度、云团尺度、颜色及种子可调。高度以世界 Y=0 为基准，相机高于云层时不显示头顶云层。没有云海或体积云功能。
- HDRI：导入等距柱状全景 `.hdr` / `.exr`（通常宽高比 2:1），自动复制到 `assets/sky_hdri/` 并通过 Godot 导入。支持旋转、亮度，以及独立选择天空补光或颜色补光。全景中拍下的太阳、云层与时刻不自动改变；太阳角度可手动对齐。导入不依赖原文件的外部路径。
- 太阳：手动高度与方位，或固定时刻与日轨朝向，两种控制互斥。按时刻采用 06:00 日出、12:00 正午、18:00 日落的美术日轨，并调整程序天空昼夜色彩；不做经纬度、日期或天文模拟。夜间太阳直射关闭。可读夜景模板使用手动冷色主光作为夜间照明。
- 环境：补光颜色、强度、固定曝光、太阳颜色、角直径及阴影。
- 雾：启用、颜色、按米设置的起止距离及浓度。结束距离必须大于起始距离。
- 天气快捷项：晴朗、多云、阴天、薄雾，一次修改实际云量、主光、补光与雾参数，整体可撤销。可继续手动细调。HDRI 的拍摄内容保持不变。
- 光照模板：内置 V1、V2 环境资源作为来源副本，可改主光、补光、曝光和雾。天空颜色、云层参数在程序天空模式编辑。模板不实例化旧云海，原 V1/V2 源场景及资源保持。

内置八个预设：中性白盒、晴朗午后、柔光阴天、薄雾清晨、暖色黄昏、可读夜景、V1 光照模板、V2 光照模板。列表缩略图是天空配色示意，实际效果在原生视口预览。

第一版固定时刻、静态云形和固定曝光，便于重复测试。雨雪、风、昼夜自动循环、天气过渡、区域天气、自动 HDRI 太阳识别以及相机观察点库暂未实现。
