# 首版白盒地形验证

日期为 2026-11-24。使用 Godot 4.7.1 在隔离工程运行专项检查。作者场景和配表未用于写入测试。隔离配表移除了一个指向缺失测试场景的旧测试记录。

| 检查 | 结果 |
|---|---|
| 原生编辑器专项 | 25 项通过。包括轮盘入口、俯视切换、恢复原透视、峰和山脊预览、山口调节与撤销、河流、高原、边界加点、复制、删除、预设及保存重读。 |
| 原有轮盘回归 | 130 项通过。包含白盒分页、机关、NPC、触发区域、载具的放置与已有资源保护。 |
| 试玩碰撞 | 两项通过。河床射线击中地形碰撞，位置低于原始模板地板。保存后的场景通过原生试玩入口启动默认角色，从山脚穿过双峰山口，900 个采样物理帧均着地。 |
| 视觉 | 导出 Godot 生成的网格并以软件着色检查双峰、山口、河床和高原。当前环境无法打开有窗口的 Godot，原生工具栏的屏幕呈现未实测。 |
| Wiki | `python3 tools/wiki/wiki.py check` 通过。中英文共 46 页，检查 2,976 个本地链接。 |

复测时使用同一份隔离工程。第一条生成试玩用场景，第二条启动此场景的真实玩家与碰撞。

```bash
godot --headless --editor --path /path/to/test-project -- --terrain-test
godot --headless --fixed-fps 60 --path /path/to/test-project --script res://tools/level_editor/test_terrain_play.gd
```

本轮新增或调整的用户可见名称包括地形、选择、山峰、河流、高原、圆丘、陡峰、双峰山口、高原河谷、完成河流和断开山脊。它们与中英文操作指南中的入口一致。
