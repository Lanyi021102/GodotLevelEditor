## 当前保留边界

- 全部编辑器及运行组件、可编辑 HUD、正常比例角色、基础第三人称操作与试玩。

- 当前角色与 NPC 的原模型、动画、纹理和许可，包括为重建服务的源文件。
- `tl_capture / tl_restore`、旧图字段与迁移读取等仍有调用方的兼容接口；这些接口不代表时间线或分身玩法仍存在。

## 后续检查

可执行只读盘点：

```sh
python3 tools/cleanup/audit_project.py --output /tmp/project-audit.json
```

该命令只报告验证工程副本、文档导入文件、临时场景和文字引用，不自动删除。动态加载、工作簿、二进制资源及当前原生编辑器打开的内容需要单独核对；“找不到文字引用”不等于可以删除。

验证工程副本和旧网站产物可移到工程外；日志、哈希和验证结论保留。清理当前项目时保留 `.godot/` 导入缓存，避免再次打开时重复导入；保留正在使用的 Wiki Python 环境与服务。
