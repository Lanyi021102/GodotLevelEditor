## 操作

| 输入 | 行为 |
|---|---|
| 鼠标移动 | 直接转动视角，灵敏度使用屏幕原始位移，不随窗口缩放改变 |
| WASD、Shift、空格、F | 相机相对移动、跑步、跳跃和交互 |
| 按住右键 | 平滑拉近并收窄视野，方便观察人物与机关；松开恢复 |
| V | 切换左右肩，便于从另一侧观察墙角 |
| 中键 | 将视角转回角色背后，恢复常用俯角 |
| 滚轮 | 在 2.2～6 m 的探索距离之间调整 |
| Esc | 释放鼠标；移动、跳跃、交互和时间快捷键停止接收输入 |
| 点击场景空白处 | 重新捕获鼠标，恢复角色与相机控制 |
| Q/E、T、R | 保留既有时间浏览、继续和固定分身操作 |

Esc 只释放控制。需要停止世界时，释放鼠标后点击原有暂停按钮；恢复控制后也可使用 Q/E、T。切出窗口会自动释放控制，避免返回游戏时镜头突然转动。回溯暂停时仍可转镜头、换肩与调整观察距离。

## 构图与遮挡

默认距离 3.8 m，观察中心在脚下以上 1.45 m，右肩偏移 0.55 m，俯角 10°，视野角 65°。右键观察距离 2.3 m，肩偏移 0.65 m，视野角 50°。这些数值可在场景的 `CameraRig` Inspector 中继续调整，包括鼠标灵敏度与垂直反转。

`SpringArm3D` 使用半径 0.18 m 的球形扫掠检查世界第 1 碰撞层，遇墙自动收近；另检查横向肩偏移，防止贴侧墙时从墙外开始后方扫掠。玩家和分身不参与相机遮挡。相机近裁面为 0.08 m。

跟随使用平滑位置；目标突然移动超过 6 m 时直接对齐观察中心，避免重置或长距离回溯时飞越整个关卡。镜头不写入时间线快照，视角调整不会改写分身录像。第三人称运行时停用微缩景深，远处人物、门和线索保持清晰；V2 的光照与曝光继续使用原配置，V1 资源保持原样。

叙事模块使用 `godot_level_editor_dialogue_player` 组与 `blocks_player_input()`：自由对话保留移动和镜头，站桩对话停止水平移动并释放鼠标；结束或切回自由句后恢复原有控制状态，窗口失焦后不自动抢回。只提供旧 `is_active()` 的适配器保持原锁定规则。没有对话模块的场景可独立运行。

## 公共接口与文件归属

- `scripts/camera/orbit_camera.gd` 保留 `target`、`arm`、`camera`、`get_yaw_radians()` 与 `_apply()`，现有会话、移动、光照和检查工具继续调用。
- 新增 `capture_mouse()`、`release_mouse()`、`is_gameplay_input_enabled()`、`snap_to_target()` 和 `recenter_behind_target()`。
- `scripts/core/game_session.gd` 绑定目标后对齐镜头；鼠标释放时停止接收时间快捷键。
- `scripts/player.gd` 仅为受控身体增加输入开关；分身重播继续使用原来的世界坐标录像和交互协议。
- `project.godot` 新增 `camera_swap_shoulder`，默认 V。三套编辑器、机关与敌人的运行接口不变。
- `scenes/main.tscn`、`scenes/3cplayground.tscn` 使用新构图。用户房间与机关源不在本轮修改范围。
