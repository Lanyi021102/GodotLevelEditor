# 3C Playground · 2026-11-02

## 使用

打开 `scenes/3cplayground.tscn` 后按 F6。F5 仍运行 `scenes/main.tscn` 连续世界；两个入口共用同一套人物、时间与 HUD。测试场使用保留的白模空岛光照 V1，没有修改其资源。

测试场是原生可编辑 `.tscn`，碰撞、箱子、标尺和相机均可在 3D 视口中调整。包含 20m 平地跑道、0.3/0.6/0.9/1.2/1.5/2.0m 箱子、连续跳台、0.65m 窄梁和真实拉杆门；2m 箱子作为当前跳高之外的对照。英文地标位于场景内，HUD 只有左上角暂停按钮。

测试物体统一使用 [米制网格材质](../whitebox_grid/README.md)：1 m 粗线、0.5 m 中线、0.1 m 细线；拉杆与门开启 `use_metric_grid`，保留通电状态变色及发光。场景内人物与文字继续使用自身材质。

## 当前操作合同

| 操作 | 行为 |
|---|---|
| WASD | 相机相对移动 |
| 按住 Shift | 跑步，松开恢复走路 |
| 空格 | 单次跳跃，支持离地宽容与提前输入缓冲 |
| Q / E 单按 | 回退 / 快进 1 秒，限制在当前保留历史范围内；完成后暂停 |
| 按住 Q / E | 首先跳转 1 秒，超过 0.3 秒后连续回退 / 快进，默认 2 倍速；松开保持暂停 |
| T | 从当前状态继续模拟，覆盖该点之后的当前玩家/世界历史 |
| R | 暂停且游标后存在录像时，将游标至历史末尾的玩家录像固定成新分身；仍暂停，按 T 开始 |
| F | 与范围内最近且可用的机关交互 |
| 左上角按钮 | 暂停 / 继续 |
| 右键或中键拖动 / 滚轮 | 相机旋转 / 缩放；Q/E 已释放给时间操作 |

Q/E 只浏览已经记录的状态；E 不能生成尚未发生的未来。暂停时按住移动键不会改变录像。R 在历史末端、无未来录像时无效；不生成空录像分身。无旧版驻影、删除分身、重置、蹲行、冲刺或键盘相机操作。跌出岛面自动重置当前尝试。

## 固定分身语义

- 玩家始终控制原身体，新建的独立身体使用深拷贝录像，播放一次后留在终点。没有能量、分裂费用、冷却或额外分身数量限制。
- Q/E 可以回到任何分身的生成点之前；录像和分身对象保留，生成前隐藏并关闭占位碰撞，到生成帧再次开始播放。
- 改写玩家历史不会删除或改写已有分身；R 仅为当前玩家新建录像。所有身体继续参与同一个物理世界和时间快照。
- 分身沿录像目标运动，但仍受门/箱子等真实碰撞影响；被挡住时按现有阻挡超时规则等待，未承诺穿透障碍后仍精确复原绝对位置。
- F 的成功动作随物理帧记录：组合实例 ID + 对象 ID + 场景路径回退。回放解析相同机关并传真实角色，重新检查可见性、距离与一次性条件；快照恢复不再次触发交互。
- 历史保留现有 90 秒环形缓冲；不可回到已覆盖帧。固定录像独立保存于会话内，不受缓冲覆盖或新分支截断影响。分身和录像仍不写长期存档。

## 调参

在测试场选择 Player，Inspector 的移动分组可调 walk_speed、run_speed、acceleration、deceleration、air_acceleration、gravity、jump_height、coyote_time、jump_buffer_time、turn_speed。正常比例角色不再在 `_ready` 中覆盖场景数值。运行时也可通过 Remote 检查器调试；需要保留的参数写回场景。

默认走速 1.8m/s、跑速 4.6m/s、跳高 1.7m；按比例角色胶囊高 1.78m。CameraRig 可调距离、俯角、跟随平滑。Root 的 scrub_speed 控制长按时间浏览速度。新分身继承生成时玩家的移动参数。

## 公共接口与兼容

`game_session.gd` 负责时间按键、分身与暂停；`main.gd` 仅扩展连续世界装配、回退组件与持续进度。默认入口、三套编辑器、用户资源和光照 V1 保留。

HUD 场景保持可在 2D 视口编辑，只发出 pause_requested。世界显示用的 set_* / flash_message 暂留无界面兼容入口。旧时间线和能量 HUD 组件已删除，旧输入映射已移除。

实际能量扣除、移动限制、分裂费用、能量快照和存档字段已删除；EnergyLedger 仅保留无效果的旧资源接口，避免现有工具或旧资源因单例名缺失不能加载。旧存档 energy_max 字段忽略，世界持续进度不变。
