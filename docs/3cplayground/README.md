# 白盒 3C Playground · 2026-11-12

打开 `scenes/3cplayground.tscn` 后 F6；F5 运行基础白盒 `scenes/main.tscn`。两个入口共用正常比例角色、第三人称镜头和可编辑 HUD。晴日微缩光照 V2 和白模空岛光照 V1 保留。

测试场是原生可编辑 .tscn，包含平地跑道、高低箱、跳台、窄梁及拉杆门。米制网格保持 1 / 0.5 / 0.1 m 刻度。

## 基础操作

| 操作 | 行为 |
|---|---|
| WASD / Shift | 相机相对移动／跑步 |
| 空格 | 单次跳跃，保留离地宽容与输入缓冲 |
| F | 与最近且可用的机关／NPC 交互 |
| 鼠标移动／右键 | 转动镜头／拉近观察 |
| V／中键／滚轮 | 换肩／回正／调距离 |
| Esc／点击场景 | 释放鼠标／恢复控制 |

掉落会回到出生点并恢复试玩前的临时机关状态。Q/E/R/T 及 HUD 暂停按钮已删除；没有录像、分身、时间浏览、能量或能力解锁。

## 参数和接口

选择 Player 调整移动、加速度、重力、跳高及动画参数。默认走速 1.8 m/s、跑速 4.6 m/s、跳高 1.7 m；胶囊高 1.78 m。CameraRig 参数见 [第三人称相机](THIRD_PERSON.md)。

game_session.gd 仅绑定角色与相机、处理掉落复位；main.gd 负责世界组装、初始状态与可选持续进度；3cplayground.gd 连接测试拉杆和门。组件 tl_capture/tl_restore 保留给编辑器、复位与调试，没有自动录制或时间线单例。HUD 可继续在 2D 视口设计布局；对话由台本组件预览。

## 验证

运行 tools/3c/test_3c.tscn，覆盖真实走跑、跳跃落地、F 拉杆开门、掉落复位、旧快捷键失效、特殊系统缺席和独立存档。HUD 和 current_world 测试复用此入口。旧时间线／分身测试随系统删除。结果见 [转型记录](../cleanup/WHITEBOX_2026-11-12.md)。
