# 演出时间轴接口

## 关卡数据

`World.performances` 是随关卡 `.tscn` 序列化的 Resource 数组。每段演出有稳定 `id`、`display_name`、`input_mode`、NPC 引用和片段。作者编辑将整段演出作为关卡场景的原生撤销事务。镜头变换、走位和途经点保存为相对关卡根的坐标。NPC 使用作用域 ID，兼容按关卡或 Room 组织的常驻及任务 NPC。重命名不改变引用。

镜头轨包含硬切起点与持续时间，可保留透视镜头视野角或正交尺寸。每个 NPC 各有走位与动作两轨。走位包括站位、移动和转向，移动按途经段长度及片段时长插值。动作引用模型已有的片段。编辑时间吸附为 0.1 秒，同一轨道的片段不得重叠。

## 编辑与运行

编辑预览在独立 SubViewport 中重建当前关卡的临时副本，采样镜头和 NPC 姿态。原生视口和场景树负责取景、选点与绑定。结束预览释放临时场景。

常驻关卡图和任务图使用 `play_performance` 节点，参数为 `performance` 稳定 ID。端口为 `run`、`completed` 和 `failed`。运行时每个关卡同时播放一段。常驻图可调度常驻 NPC，任务图可另调度同任务 NPC。演出完毕恢复玩家原镜头和输入状态，保留 NPC 最终站位并恢复其行为。取消演出恢复开播前站位。检查点等待演出结束后才可保存。

操作见 [关卡指南](../wiki/guides/levels.md#performance)，实测见 [验证记录](validation.md)。
