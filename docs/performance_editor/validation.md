## 重跑专项测试

在隔离副本先用 Godot 导入工程，再运行以下命令。第一条命令会输出 `PERFORMANCE FIXTURE`，把它后面的场景路径传给第二条。

```sh
godot --headless --editor -- --godot-level-editor-suite-test --performance-editor-test
godot --headless --script res://tools/performance/play_test.gd -- --fixture=res://tools/performance/.fixture_<PID>.tscn
```

操作入口和新增中文标签已经按项目命名约定核对。详见 [双语关卡指南](../wiki/guides/levels.md#performance) 与 [演出接口](INTERFACES.md)。
