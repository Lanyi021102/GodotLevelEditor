# 编辑器功能地图

先按你要制作的内容找到入口，再进入对应指南。下列名称以 2026-11-17 的项目界面和模块说明为依据。

## 入口在哪里

独立窗口首次打开先显示工作台，其他分类按需准备；打开 Godot 时，原生三维工具与保存保护已可使用。

旧“关卡摆放”侧栏及其旧素材库已移除，摆放统一使用原生 3D 轮盘。参数在检查器修改，关卡由 Godot 原生场景树、文件系统、保存和试玩管理。

| 我要制作 | 使用入口 | 用来做什么 | 继续阅读 |
|---|---|---|---|
| 界面偏好与文档 | 最左侧 GodotLevelEditor 标志：工作台 | 调整本机缩放、开关动画、打开 Wiki | [工作台](guides/workbench.md) |
| 地形、建筑、通道、白盒物件 | Godot 原生 3D 视口 | 通过轮盘添加物件，编辑位置、旋转、尺寸及点线面 | [关卡操作](guides/levels.md) |
| 查找或新建完整关卡 | 关卡 → 我的关卡 | 搜索、浏览和打开原生地图；新建后原生另存、F6 试玩 | [关卡操作](guides/levels.md) |
| 整关始终有效的逻辑 | 关卡 → 关卡编辑 | 常驻触发、机关联动、NPC 互动与接取任务 | [常驻关卡图说明](../level_editor/level_logic_2026-11-15/README.md) |
| 独立机关素材 | 机关 → 我的机关 → 机关编辑 | 选择独立组件、设置状态、编辑与预览 | [使用独立机关](tutorials/button-door.md) |
| 事件及有先后顺序的目标 | 任务 → 事件与任务 / 任务图 | 创建事件和任务、绑定关卡、编排触发和完成条件 | [套件说明](../godot_level_editor_suite/README.md) |
| 对话与角色台词 | 台本 | 管理对白段落、角色与每句自由／站桩对话类型 | [台本操作](guides/dialogues.md) |
| NPC 状态机 | NPC → 我的NPC → 编辑页 | 编辑敌人／NPC 定义与状态转换 | [NPC / 敌人说明](../enemy_editor/README.md) |
| 天空、太阳、雾与曝光 | 天空 | 编辑和另存预设，预览后绑定到关卡 | [天空与关卡环境](guides/sky.md) |
| HUD 排版与样式 | Godot 原生 2D 视口 | 编辑 `addons/godot_level_editor/scenes/hud.tscn` 和 HUD 主题 | [HUD 说明](../hud/README.md) |
| 基础角色操作和镜头 | 打开 `content/scenes/3cplayground.tscn` 后 F6 | 检查移动、跑跳、镜头及交互 | [3C 测试说明](../3cplayground/README.md) |

## 三类逻辑如何分工

| 逻辑 | 何时运行 | 适合放什么 |
|---|---|---|
| 机关图 | 机关实例在运行且启用时 | 按钮控制门、压力板组合、终端控制升降台 |
| 常驻关卡图 | 关卡运行时，不依赖接取任务 | 与常驻 NPC 对话、触发环境机关、接取事件首项任务 |
| 任务图 | 事件已接取／启动，且它是当前关卡的当前任务时 | 等待目标到位、更新子目标、完成或失败任务 |

库中的按钮、门、压力板和升降台独立运行。跨机关联动由作者在关卡图或任务图中绑定具体实例；“门完全打开后完成当前任务”可等待该门的真实 open 状态。

新建门提供 **2×3 单开门 / 4×3 双开门**，节点中可直接查看门框、门扇、close / moving / open 与旋转曲线；操作见 [查看和调整旋转门](tutorials/rotating-door.md)。

## 素材与实例如何分工

在“我的机关”编辑的是**可复用素材**。把素材放进关卡后，场景里的每一份是一个**实例**。实例的位置和任务归属在当前关卡中保存，修改源素材则可能影响所有使用它的关卡。

准备制作自己的机关版本时，先在机关编辑页 **另存为**；放置时选择新版本。见 [独立机关教程](tutorials/button-door.md#own-copy)。

## 常驻对象与任务对象

轮盘添加 NPC、Room 和机关时，先选择 **关卡常驻** 或 **任务对象**。

- **关卡常驻：**随关卡存在，适合门、区域检测和负责接取任务的 NPC。
- **任务对象：**绑定本关的一个任务，只在任务 active 时显示和启用。未激活、完成或失败后关闭显示、处理与碰撞。

Room 使用箱体检测，默认 1×1×1 m。关卡 Room 为半透明深绿，任务 Room 为半透明浅绿；玩家进入后激活，可在两类图中使用进入／离开事件和“Room 是否激活”条件。操作及状态区别见 [Room 触发区域](guides/levels.md#room-triggers)。

NPC 阵营目前用于实例配置与占位颜色；默认动作会播放模型中已有的匹配动画。完整阵营战斗、巡逻路径执行及行为引用接入仍有边界，详见 [轮盘实例说明](../level_editor/quick_add_v2_2026-11-15/README.md)。

## 从场景树绑定节点对象 {#scene-reference-drop}

1. 打开正在编辑的关卡场景，进入 **任务 → 任务图** 或 **关卡**。任务页可点“使用当前世界”刷新关卡绑定。
2. 在原生 **场景树（Hierarchy）** 找到物件，从树中拖到节点底部对应的 **场景对象／NPC／房间／角色／机关 / 组件** 框。也可以拖到右侧参数区的同名框。
3. 可接受的对象会让框变蓝；松手后立即显示绑定对象，右侧菜单同步选中，无需点“应用参数”。例如把敌人物件拖到“显示／隐藏物件”（可重命名为“移除已击败敌人”）的“场景对象”框。
4. 正常保存图；Ctrl/Cmd+Z 或“撤销”可恢复之前绑定，下拉菜单仍然可用。

模型子节点会识别到所属物件。只接受当前关卡中适用的已放置对象；分组文件夹、素材文件、多选和其他关卡的对象不会覆盖原绑定。组合机关有多个组件且未指定主输出时，拖具体组件或从菜单选择。替换为不同机关后，重新选择不兼容的状态／动作。

实现边界和实际测试见 [拖放绑定验证](../level_editor/scene_reference_2026-11-16/validation.md)。

## NPC 示例素材与动画

第一版提供 13 个带骨骼的角色：小／中／大体型男女各一组、4 种动物和3种怪物。在 **NPC → 我的NPC** 中搜索并打开，在 **模型与动画** 中预览；放置时使用三维轮盘 NPC 二级菜单的 **已有素材**。具体角色、兼容动作、自然静止和另存步骤见 [NPC 素材与动画](guides/npc-samples.md)。

## 如何读旧专项文档

本 Wiki 的操作指南按当前工作流整理。模块原有 README、INTERFACES 和验证记录继续保留，页面顶部会提示其包含专项或阶段资料。

如果同一旧页面既写了 CSV 又写了 XLSX，或同时出现旧入口和新入口，先看最新覆盖说明。当前任务与台本数据使用 XLSX，当前箱庭关卡不需要房间接驳图，时间线与分身玩法已删除。

需要继续开发时，从 [开发维护索引](development/index.md) 查到模块负责人文件、接口和验证入口。


## 左上角事件与任务列表 {#task-tracker}

接取事件后，左上角第一行显示事件中文名，下一行缩进显示当前任务中文名。完成时任务文字先划掉并淡出，再渐显下一项；事件全部结束后从列表移除。多个已接取事件各显示自己的当前任务。

事件和任务名称在“任务 → 事件与任务”编辑。需要改位置或动画时，在原生 2D 视口打开 `addons/godot_level_editor/scenes/hud.tscn`，选择 `Root/TaskTracker`；具体参数见 [HUD 说明](../hud/README.md#task-tracker)。对话期间列表暂时隐藏，读档后显示恢复时的当前任务。


## 任务图工具与节点分类 {#task-graph-tools}

需要从接取到完成走一遍时，可试玩关卡 9“编辑器流程测试”。其常驻图、三个顺序任务和子图共 41 条连线通过真实鼠标拖拽建立，操作与复测范围见 [流程测试](tutorials/editor-flow-test.md)。

任务图左侧常用操作为 **添加节点、保存、撤销、重做、适合画布**。其余操作按功能收进菜单：

| 菜单 | 操作 |
|---|---|
| 文件 | 打开任务图、新建任务图、另存任务图、保存后重载 |
| 编辑 | 复制、粘贴、删除、整理节点 |
| 绑定 | 使用当前世界、使用台本页当前库 |
| 试玩 | 打开对话试玩 |

点击 **添加节点** 后，左侧直接选择全部、触发、动作、判断、状态、数据或流程，无需展开下拉框。右侧默认按类别分组；分类标题、色块与画布节点职责色一致。输入中文、英文或 kind 可搜索，清除后返回完整分类。双击结果或选择后点“确定”添加；搜索框中按向下键可进入结果列表。没有匹配结果时不能添加节点。

任务图与常驻关卡图共用分类外观，各自仍只显示适用的节点。保存时的任务关联问题见 [缺少所属任务](faq.md#task-owner)。
