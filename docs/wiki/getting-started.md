# 快速开始

完成后会有一个通过 Godot 原生保存、可用 F6 试玩的白盒关卡。

## 1. 打开工程

使用 Godot 4.7.1 打开自己的工程并[安装插件](plugin-install.md)，或者直接打开源码工程的 `project.godot`。等待导入完成，启用 GodotLevelEditor。

## 2. 用原生场景创建地图

1. 在 Godot 文件系统找到 `addons/godot_level_editor/templates/empty_level.tscn`。
2. 右键选择 **新建继承场景**。
3. 用 Godot **场景 → 另存为**，保存为 `content/scenes/levels/my_first_level.tscn`。

模板提供地面、出生点、天空和空逻辑。地图是普通 `.tscn` 场景，使用原生场景树、检查器与 3D 视口编辑。首次保存会登记供任务使用的关卡 ID。

## 3. 摆放白盒与素材

点击原生 3D 工具栏 **呼出轮盘**，或短按反引号键／鼠标侧键。选择 Layout 白盒并点击体块，在地面左键放置；滚轮翻页，R 旋转，右键／Esc 结束。NPC 和机关可以选择已有素材。移动、旋转、缩放与撤销沿用 Godot。

点线面选择工具和 0.1／0.5／1 m 步长继续可用。更多操作见[关卡与轮盘](guides/levels.md)。

## 4. 保存和 F6 试玩

检查出生点位于可站立地面上方，使用 Godot 原生保存，再按 **F6** 运行当前地图。角色、镜头、HUD 和常驻逻辑会在运行时接入，不写进地图文件。

WASD 移动，Shift 跑步，空格跳跃，F 交互；Esc 释放鼠标，点击游戏画面恢复。停止后继续编辑。F5 运行工程指定的主场景，插件不替用户更改主场景。

## 5. 编辑任务与关卡逻辑

顶部 GodotLevelEditor 打开独立窗口。“关卡”只显示当前原生场景的常驻逻辑；“任务”“台本”“机关”“NPC”“天空”继续提供各自的编辑页。

完成检查：地图文件出现在 Godot 文件系统中；关闭重开后布局保留；F6 能从出生点开始试玩。
