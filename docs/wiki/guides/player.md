# 玩家 3C 预设

一个玩家预设包含角色能力、镜头、控制和动作片段。几个关卡可以共用一份预设，也可以为各自的路线和玩法选择不同的预设。

## 创建并应用到关卡

1. 打开一个原生关卡场景，使用 Godot **场景 → 另存为** 将它存到插件目录以外。
2. 在 GodotLevelEditor 点击 **玩家 → 新建预设**。填写名称，保留内置角色或选择自己的 3D 场景。
3. 在 **角色** 开关能力并调整数值，在 **镜头** 和 **控制** 设定相机与输入。**动作** 页可以选择、播放模型自带的动画。
4. 点击 **保存预设**，再点 **应用到当前关卡**。使用 Godot 保存场景，然后按 F6。
5. 在 **关卡 → 关卡编辑 → 玩家预设** 可切换到另一份预设或选择 **默认第三人称**。切换支持 Godot 撤销和重做。

用 **复制预设** 保存另一种能力组合。多张地图引用同一文件时，保存对该预设的编辑会影响这些地图下次运行。预设位于项目的 `content/resources/player_presets/`，关卡保存资源引用。

## 能力与默认操作

| 能力 | 初始状态 | 默认操作 |
|---|---|---|
| 行走、跑步、跳跃、交互 | 开 | WASD、Shift、空格、F |
| 冲刺、蹲行、闪避翻滚 | 关 | Ctrl、C、Q |
| 二段跳 | 关 | 开启跳跃后，在空中再次按空格 |
| 自动上台阶 | 关 | 向低台阶移动，参数控制可踏上的高度 |
| 翻越、抓边上台 | 各自关 | E。薄障碍可翻到另一侧，宽平台可抓边上台 |
| 可驾驶载具 | 开 | 接近载具按 F 上车。见 [载具预设](vehicles.md) |
| 攀爬 | 关 | 在攀爬区按 X 开始或停止，W/S 上下移动 |
| 近距观察、换肩、回正 | 开 | 右键或 Z、V、中键或 R |

在 **控制** 点击按键框可以重新绑定键盘和手柄按键。左摇杆移动，右摇杆观察。基础视角可选择越肩、第一人称和固定角度。固定角度随角色移动，保留配置的朝向。

制作梯子时，在 **玩家** 点击 **添加攀爬区**，用原生 3D 视口把区域放到梯子前方。使碰撞盒覆盖梯子的可攀高度，并让区域的本地 +Z 指向梯子的外侧。移动到区域边缘或再次按攀爬键会退出，之后角色受重力影响。

## 动作来源和自定义模型

内置模型沿用 Quaternius 的 CC0 素材。待机、走、跑、跳、落地和蹲行沿用项目内的片段，冲刺、翻滚、交互从同一套动画资源重定向。梯子攀爬和跨步越障从 [CMU 动捕库](https://mocap.cs.cmu.edu/) 裁剪并重定向，`moves/Climb` 默认绑定，`moves/StepOver` 可以绑定到上台阶。翻越、抓边使用项目白盒动画。可在 [Quaternius Universal Animation Library 2](https://quaternius.itch.io/universal-animation-library-2) 查看扩展动作包。

使用自己的角色时，选一个以 Node3D 为根且含有 AnimationPlayer 的场景。在 **动作** 页为各能力选择该场景已导入的片段。缺失的片段可以留空，能力开关和位移仍按预设运行。模型和动画先在 Godot 中导入并完成骨架映射后，再在这里绑定。

要给内置模型加新动作，将动画 GLB 放入项目并等待 Godot 导入。在 **动作 → 附加动画包** 选择该文件，再选以 `imported/` 开头的片段。相近的 Quaternius 骨架会按骨骼名称重定向。其他骨架可在 Godot 中重定向，再从角色场景选择片段。
