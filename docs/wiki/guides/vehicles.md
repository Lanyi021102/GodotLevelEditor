# 载具预设

在关卡里放置、编辑和试玩可驾驶载具。内置 **卡丁车**、**摩托车** 和 **悬停飞行器**。

## 放一辆可驾驶的车

1. 在原生 3D 视口点击 **呼出轮盘 → 载具**，选择一个预设，在地面上左键放置。蓝色箭头指向载具的前方。
2. 选中载具，在检查器调整驾驶、外观与碰撞、上下车和驾驶镜头。
3. 保存关卡并按 F6。走到蓝色上车点一侧，按 F 上车。停稳后再次按 F 下车。左侧被挡时尝试右侧，两侧都被挡时留在车上。

| 操作 | 默认键位 |
|---|---|
| 前进、刹车和倒车 | W 前进，S 刹车，停稳后继续按 S 倒车 |
| 转向、观察 | A/D 转向，鼠标观察，中键将驾驶镜头转回车尾 |
| 飞行器升降 | 空格上升，Shift 下降。自定义玩家预设还可用蹲行键，默认为 C |
| 上车、下车 | F；悬停飞行器须降落后才能下车 |

使用自定义玩家预设时，方向、交互和升降跟随该预设的键位。可在 **玩家 → 角色** 调整 **可驾驶载具**。

## 把自己的模型存成预设

1. 放一个接近目标体验的模板。选择驾驶类型，再把 Godot 已导入的 GLB、GLTF 或三维场景拖入 **Model Scene**。用模型偏移、转角和缩放对齐外观。模型留空时显示对应的白盒外形。
2. 用 **Body Size** 和 **Body Center** 调整蓝色碰撞框。蓝色十字表示上车点，黄色是驾驶姿态原点，绿色是左右下车点。更换外形后检查地面、座位和站人空间。
3. 默认角色使用 Quaternius 的坐下、坐姿和起身片段。角色有专用动画时，在 **Board Animation**、**Seated Animation** 和 **Exit Animation** 填写 AnimationPlayer 的片段名。具名动画库的写法为 `库名/片段名`。
4. 点击检查器顶部的 **保存为载具预设**，保存到 `content/scenes/vehicles/`。随后在其他关卡打开 **轮盘 → 载具**，可以按显示名称找到这份预设。

载具实例随关卡场景保存。内置地面载具使用简化加减速和碰撞，飞行器可悬停。模型与许可见 [素材来源](../../vehicle_editor/INTERFACES.md#vehicle-sources)。
