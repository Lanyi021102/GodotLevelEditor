# 术语与快捷键

## 常用术语

| 名称 | 在这个项目中的含义 |
|---|---|
| 关卡 / 箱庭 | 一个完整的大世界 `.tscn` 场景，包含地形、建筑、区域、机关与 NPC |
| Room | 检测玩家进入的箱体触发区域，默认 1×1×1 m；进入后激活，可驱动任务图和关卡图，见 [Room 操作](../guides/levels.md#room-triggers) |
| Layout 白盒 | 用于搭建、修改空间形状的白盒物件 |
| 素材 / 源场景 | 可复用的场景或定义；修改可能影响它的多个实例 |
| 实例 | 某个素材放入关卡后的一份具体对象，拥有自己的位置和引用标识 |
| 机关组合 / Assembly | 包含组件与机关图的可复用整体，场景和图定义成对保存 |
| 常驻关卡图 | 不依赖任务是否接取的整关逻辑 |
| 事件 | 包含一组按顺序执行任务的流程，事件本身不绑定单一关卡 |
| 任务 | 事件中的一个目标，必须且只能绑定一个关卡 |
| 任务对象 | 绑定任务生命周期的物件，仅在对应任务 active 时启用 |
| Comment | 台本中一次可调用的对白段落边界；不同于顶层整理用对话组 |
| 稳定 ID | 程序用于引用对象、节点或任务的标识；显示名称不承担绑定职责 |
| 状态 / 事件信号 | 状态表示“现在是什么”，事件表示“刚刚发生了什么” |

## 编辑与放置

| 操作 | 按键 / 入口 | 适用位置 |
|---|---|---|
| 运行主入口 | F5 | Godot |
| 运行当前场景 | F6 | Godot，完整关卡可自动接入试玩组件 |
| 呼出 / 关闭轮盘 | 工具栏、反引号或鼠标侧键短按 | 原生 3D 视口 |
| 放置 / 连续放置 | 地面左键 | 放置预览中 |
| 正向 / 反向旋转 15° | R / Shift+R | 放置预览中 |
| 白盒轮盘翻页 | 滚轮向上／向下，每页 8 个 | 白盒二级轮盘中 |
| 白盒轮盘下一页 | 按下滚轮（中键） | 白盒二级轮盘中 |
| 返回上级轮盘 | 右键 | 二级轮盘中 |
| 结束放置 | 右键 / Esc | 放置预览中 |
| 保存场景 | Godot 原生保存 | 当前场景 |
| 保存全部 | 独立窗口右上角 … 菜单 | 场景和编辑器数据 |

原生撤销、重做和保存按当前操作系统的 Godot 键位设置使用。轮盘呼出键可在工具栏旁的菜单修改。

## 角色与镜头

| 操作 | 按键 |
|---|---|
| 移动 / 跑步 | WASD / Shift |
| 跳跃 / 交互 | 空格 / F |
| 转动镜头 | 鼠标 |
| 拉近观察 | 按住右键 |
| 左右肩切换 | V |
| 调整镜头距离 | 滚轮 |
| 镜头回到角色背后 | 中键 |
| 释放鼠标 / 恢复角色操作 | Esc / 点击游戏画面 |

这些为试玩状态的默认键位。放置模式中的 R 和历史文档中的时间线按键含义不同；当前试玩已删除时间线相关操作。
