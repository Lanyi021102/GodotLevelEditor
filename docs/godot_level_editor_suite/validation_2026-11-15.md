# 独立关卡试玩与编辑窗口验证

Godot 4.7.1，macOS，2026-11-15。

根因：新建关卡只包含世界布局、出生 Marker、光照和机关。独立运行该场景时没有玩家、镜头或 HUD；这些原先只存在于主入口。此前窗口焦点修复会在试玩时隐藏整个插件窗口。

修复：world.gd 仅在自身作为独立运行场景时创建 PlaySession，复用当前角色、镜头、HUD 和出生点／复位逻辑。main.gd 的 world_path 默认值保持原主入口；试玩组件指向父关卡。不会把试玩组件保存进用户关卡。F5/F6 保留编辑窗口现有可见性，只收起模态弹窗，并继续抑制自动切页和抢焦点。
