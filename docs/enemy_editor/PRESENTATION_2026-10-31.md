# 敌人蓝图呈现统一 · 2026-10-31

## 修改内容

- 只读复用机关 `graph/node_presentation.gd` 的六类色表、方向行、端口行、边框和活动色；敌人适配器位于 `addons/enemy_editor/graph/node_presentation.gd`。
- 现有四状态及新增的 FSM 状态都是持续状态，统一为“状态 · 名称”和青绿色 `#24756e`。噪音/求援是一次转换事件，条件是转换规则；本次不将它们新增为图节点或修改现有语义。
- 画布提供六类颜色与文字图例：判断 `#94700e`、触发事件 `#a34439`、状态 `#24756e`、动作 `#345f96`、数据/引用 `#71508f`、延迟/流程 `#9b592b`。分类色与端口/连线色分开说明。
- 方向行左侧“输入 →”、右侧“→ 输出”；端口行分别显示“状态进入”“条件转换”，名称靠近对应连接点。节点内另标 `[状态转换]`，悬停仍提供稳定端口 ID、类型及连接语义。共享方向函数在无端口侧不显示方向标识。
- 选中、运行、暂停和回溯时保持分类底色；活动提示使用绿色边框、绿点及状态文字。取消整节点调色与非活动节点透明度衰减，保留实际计时/警觉及最近转换原因悬停显示。
- 固定节点内字号以兼容现有布局，避免高缩放编辑器字体使节点变宽遮挡；不调整资源中的节点位置。

## 接口影响

- 节点 ID、端口 ID、端口类型、GraphEdit 连接索引、定义资源、场景引用和运行执行器均保持原样。方向行是 slot 0（无端口），端口行改在 slot 1；**启用输入/输出的连接索引仍为 0**。
- 新增的 `session_pause_changed` 仅为敌人插件内部呈现信号，监听 Godot 调试会话暂停/继续，不向游戏写消息；运行调试包与快照格式未改。回溯冻结仍读取原 `rewound` 标记。
- 本次代码变更限于敌人插件呈现、其内部调试显示接线和专项测试。运行脚本、首个 `.tres` 定义、公共守卫、`project.godot`、机关参考实现的文件摘要均与开工时一致，见验证摘要。
- 测试探针新增 `--hold-enemy-visual` 可选参数，供实际调试回溯截图观察，默认自动验证流程不变。
