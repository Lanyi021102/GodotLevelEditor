    界面、关卡仓库与任务关卡绑定验证¶

    Godot 4.7.1，macOS，2026-11-13。先完成 headless 检查，再用 Metal Forward+ 渲染独立窗口。

    检查 结果
    套件编辑器，headless 52 项通过
    套件编辑器，Metal 实际窗口及截图 53 项通过
    任务运行与跨关卡隔离、续接 49 项通过
    节点呈现、端口与图数据保持 139 项通过
    NPC 状态图编辑、端口、撤销及场景绑定 42 项通过
    F5 启动及待提交弹窗收起、焦点 11 项通过
    五类仓库原生视口文件放置 5 项通过
    场景／资源外部引用 缺失 0 项
    git diff --check 通过

    检查了“我的关卡”、各仓库、任务／台本／机关／NPC、任务新建窗口和关卡图截图。四列卡片在 1504×1000 窗口中完整显示，缩略图对应真实关卡，备注保留实际内容。工作簿更改经过渲染及游戏侧读取。

    动画只修改编辑器 Control：页面和详情透明度、导航缩放、卡片缩放与阴影。动画结束后恢复正常状态，不改变目录行和关卡数据。测试中场景保存仅针对临时新建关卡，不保存用户原场景。

    原生放置测试使用仓库实际的 files 拖放数据，经 Godot 原生视口创建场景实例；不把它描述为操作系统鼠标跨窗口拖放测试。

    部分测试进程退出时仍输出既有 Plugin is not attached to debugger 清理日志；上述检查结果通过，实际操作及渲染阶段未出现新的脚本错误。
