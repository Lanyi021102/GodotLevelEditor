    GodotLevelEditor 独立编辑窗口¶

    2026-11-15 资源入口统一：点击一级“关卡／机关／NPC”先进入“我的关卡／我的机关／我的NPC”。单击卡片查看详情，双击或“进入编辑”打开具体资源。机关和 NPC 的新建入口移到目录卡片；编辑页保留保存、另存为、撤销、验证和节点操作。二级编辑页签仅在已有打开资源时可用，返回目录保留草稿。目录支持搜索、刷新与窄窗口换列；详情显示资源名、节点／状态数量及路径。机关目录收录 scenes/mechanisms/ 内的机关组合，单体拉杆、门等组件仍从关卡素材仓库编辑；NPC 目录收录 resources/enemies/ 内的状态机定义。验证见 目录导航检查。

    2026-11-12。打开项目后，点击顶部 GodotLevelEditor，或“项目 → 工具 → 打开 GodotLevelEditor”。窗口可以移动到其他显示器；关闭窗口只隐藏，不丢失编辑内容，重新点击入口即可恢复。Godot 关闭时插件一起关闭。

    顶部主导航为关卡、任务、机关、台本、NPC、其他，更多菜单保留保存全部及打开配表文件夹。使用冷灰工作区、白色页头与面板、蓝色强调（#2563eb），一级导航选中为实蓝底、白色文字；二级页签使用蓝色文字和下划线，两级之间有细分隔线，页头不再重复显示产品名。任务分类下再切换事件与任务表和任务图。各模块继续使用原来的场景、图资源、编辑器撤销和运行组件。

    初始窗口 1504 × 1000，最小 1100 × 760，可自行缩放并记住位置和尺寸。“我的关卡”采用四列白色卡片、真实关卡缩略图、固定 ID 与名称，以及独立的白色详情栏；窄窗口减少列数。卡片使用细边框、轻阴影和蓝色选中轮廓，没有备注的关卡不填入示例文字。任务、机关、关卡和 NPC 图均提供带边框的浅灰画布、细方格与稍深的主网格；节点使用白色正文，保留标题职责色与端口类型色。

    动画只用于编辑器：一级菜单选中后字重 700，背景 0.16 秒亮起及 0.22 秒轻阴影反馈；二级页签下划线 0.18 秒淡入，关卡卡片选中底色和边框 0.18 秒过渡并带 0.24 秒阴影脉冲。页面、详情及仓库子页使用 0.14 秒淡入；图节点选中后 0.24 秒边缘微光淡出。卡片、菜单及节点不缩放，不移动，不更改点击区域或端口。连续操作中断旧动画，导航和卡片隐藏时复位。所有动效仅修改编辑器 UI 或其私有样式资源，不涉及游戏、角色或场景环境。

    F5/F6 开始试玩时，已打开的插件窗口继续保留；关闭未提交的弹窗以解除模态焦点，运行期间的自动页面回调不会重新打开窗口或切换页面。手动关闭后保持关闭，仍可从菜单打开。切到编辑器时游戏释放鼠标，点击游戏画面恢复角色操作。

    事件与任务¶

    • 事件行展开后显示内部任务，右键管理新建、复制、删除、信息和执行顺序。事件本身不绑定关卡。
    • 新建任务打开独立窗口：数字任务 ID 自动分配且不可改，填写任务名、任务中文名并选择唯一关卡。关卡选项可按 ID、名称、中文名搜索，未选择不能提交。
    • 所属关卡列显示关卡中文名；事件行汇总其子任务的关卡，任务行只显示自己的一个关卡。一个事件中的不同任务可以绑定不同关卡。
    • 事件 ID 从 1001 开始；任务为 1001001、1001002……。分配后固定，删除不回收，撤销不回退计数。排序使用独立 order，复制分配新 ID。
    • 程序名用于记录及调用，显示名用于 HUD，备注仅供制作。事件程序名在配表中唯一，任务程序名在所属事件内唯一。
    • 双击事件或使用右键“编辑信息／开始条件”，配置程序调用、进入 Room、收到指定事件或游戏开始四种条件。
    • 点击任务行“编辑”打开对应任务图和其绑定关卡，没有文件时自动新建。新图包含开始和完成节点，完成节点初始不连线；配置实际完成条件后，任务才会完成。
    • 图中的任务 ID 自动绑定当前行，不能在参数面板重新编号。

    运行时，一个事件内部仅当前任务执行，完成后按 order 激活下一项。当前任务只有在所属关卡才执行；其他关卡的 Room／NPC 信号不能推进它。未开始的任务不会提前消耗触发；不同事件可以独立进行。默认最后一项任务完成即结束事件。

    特殊流程：使用“等待显式结束事件”节点取消自动结束，之后由“结束当前事件”节点结束；也可直接使用结束节点提前结束当前事件。事件一旦完成，不会因重复进入 Room 自动再开始。

    XLSX 配表¶

    统一目录 配表/：

    • levels.xlsx：“关卡”“配置”分表，保存关卡 ID、名称、中文名、场景路径、备注、缩略图路径和分配计数。
    • events.xlsx：版本 2，“事件”“任务”分表，任务新增必填 level_id；事件没有 level_id。另有用于保存版本和分配计数的“配置”页。
    • dialogues.xlsx：“对话组”“Comments”“对白”“角色”“配置”页，保留已有对白、颜色及编号。

    编辑器保存和游戏读取都使用 XLSX，不再要求中转 CSV。表格表头为固定字段，ID 以文本保存；配表使用直接值，不执行 Excel 公式。可在 Excel 中修改，关闭文件后在编辑器重新读取。不要同时保存 Excel 和编辑器中的不同草稿。

    任务图仍是独立 .tres 图资源，任务表的 graph_path 保存对应路径，默认位于 resources/task_graphs/。这是图编辑数据，不是另一份任务配表。

    旧 .tres 台本和任务图保留；旧 CSV 备份在 resources/narrative/legacy/，不被当前执行器读取。原对白和 comment ID 迁移后保留。旧报到任务复制为事件 1001 的任务 1001001，原任务图不覆盖；旧版运行进度没有强行改写为新事件进度。

    关卡及现有编辑器¶

    关卡编辑的是大世界常驻内容。“我的关卡”可选择、新建、编辑信息或进入编辑；删除只移除目录记录，场景保留，被任务引用的关卡禁止删除。“关卡编辑”直接提供整关常驻逻辑图，空间素材统一由三维视口轮盘添加；一个箱庭对应一个完整场景，不使用房间接驳图。新建关卡自动分配数字 ID，填写关卡名、中文名和可选备注后创建世界场景；目录统一为 scenes/levels，初始包含基准地面、出生点和保留光照。关卡名称可单独修改，场景路径及 ID 保持稳定。

    空间对象的素材选择、放置及实例属性由三维轮盘负责，独立窗口不再重复提供素材仓库和已放置列表。关卡图中的 NPC 只从当前关卡常驻对象中选择；“接受任务”在备注区搜索当前关卡的事件首项任务，接取后自动推进其后续任务。关卡逻辑与任务使用同一对话服务，尚未接取任务时也可触发常驻对话。保存场景写入 .tscn，关卡目录信息保存至 levels.xlsx。

    玩家出生点使用 spawn_marker，role=player。已有白盒的出生点位置与原玩家初始位置一致。主入口读取第一个玩家出生点，更新玩家及复位位置；其他出生点角色不作为玩家初始点。常驻 Room 默认使用不要求拓扑连线的检测区域，独立于任务是否启动；既有需要连线的房间素材仍保持拓扑检查。这里的素材是关卡常驻内容，不会随任务创建或删除。

    直接 F6 运行大世界关卡时，world.gd 检查自己是否为当前运行场景，并在运行时载入 play_session.tscn，复用现有玩家、镜头、HUD 和复位逻辑。嵌入主入口的世界不重复生成角色；试玩不把组件写进用户场景，也不读写长期进度。此处理兼容已经创建的关卡。

    三维编辑仍在 Godot 原生视口，套件没有镜像视口。HUD、脚本等原生编辑功能保持。

    界面只显示必要名称、参数和操作。节点分类只用颜色；类别前缀、空运行状态、常驻操作说明和格式标签不显示，解释保留在悬停提示中。有真实运行数据时才显示调试数值。

    接入与试玩¶

    现有场景可添加 addons/godot_level_editor_suite/runtime/event_director.gd 节点，配置 workbook 和 world_path；默认配表为 res://配表/events.xlsx。NPC 继续实例化 scenes/narrative/npc.tscn，设置 object_id，任务图通过 ID 关联。

    专项样例是 tools/narrative/session_fixture.tscn，F6 运行。默认配表中的报到任务通过进入 atrium 启动。正式白盒入口不自动接这个样例。

    浅色界面与节点网格 · 2026-11-15¶

    统一导航、目录卡片、素材库、表格、弹窗与节点画布的间距和颜色；收紧导航及节点工具栏。网格仅改变显示，不改变吸附、缩放、画布位置、连线、稳定 ID 或运行逻辑。实际渲染截图和本次检查记录见 视觉更新验证。

    同日导航细化：移除页头产品名，一级导航使用蓝底白字，二级页签使用蓝字下划线，并以细线分隔。验证与截图见 导航层级调整。

    同日选中反馈：一级菜单仅在选中时加粗，菜单、页签、关卡卡片、节点与详情区加入短时选中反馈；支持新增天空一级导航。验证与动态预览见 选中动画验证。
