    GodotLevelEditor：当前游戏设计¶

    2026-11-12：本游戏设计已暂停，项目转为个人白盒编辑器；时间、分身、能量及能力解锁已移除。以下作为历史设计资料，不作为当前实现要求。

    更新：2026-11-12。

    已确定的方向¶

    游戏定位为氛围和剧情相对轻松、王道的第三人称解谜与潜行箱庭游戏。玩家扮演“时间管理局”的特工，使用特殊的分身和时间控制能力，穿梭于不同时间线，在尽可能不惊动当地人的前提下，回收不属于当地时间线的道具并撤离，保障各条时间线的安全。

    本次调整替换此前的故事方向。先前的蒸汽朋克主角与科幻遗迹叙事不再作为全游戏默认背景；具体任务仍可采用适合的时代与场所。

    • 主要乐趣：观察场所与人员规律，利用时间和分身安排合作，找到取物及撤离的方法。
    • 剧情气质：积极、有冒险感，角色之间可以有幽默和温情；具体角色、冲突与结局见建议稿。
    • 内容制作：用户亲自编辑关卡、敌人、机关与参数；Agent 提供工具、底层能力、技术支持和验证。
    • 完整故事建议见 时间管理局剧本方案。其中明确区分用户已确定内容和可调整的创作建议。

    2026-11-05 · 用户补充的关卡与交互构想¶

    三个关卡方向为：蒸汽朋克剧院（多路径潜入，在演出高潮于舞台中央取物）、远古群居洞穴（通过图像与人物活动推断目标位置）、赛博朋克政府大楼（运用科技道具，并应对强敌）。这些方向优先于此前由 Agent 提出的钟楼、温室和码头案例。

    NPC 不默认敌对。玩家可以通过交涉和许可拿取物品，也可以伪装、偷窃、翻入或使用暴力；行为会改变后续警戒与世界。玩家头顶气泡提供交涉、沉默、暴力等交互。具体规则尚未定稿或实现；原作调研和可选方案见 潜行与社会互动调研。

    本轮结构建议，尚未实现¶

    建议使用“局内中枢 + 多个任务箱庭”：接收任务 → 进入目标时间线 → 调查异物 → 解谜潜入 → 带物撤离 → 归档及后续任务。

    每个任务内的房间与路线连续相通，保留探索、高差、支路和捷径。跨时间线旅行作为任务间结构；首个白盒不要求在同一关中随时切换多个时代。

    此前讨论的轻度类银河城要素，可以通过局内装备授权和旧任务的新路线保留为可选扩展。本轮优先验证单个箱庭的回收与撤离，并按用户的新构想验证暴力作为可选解法时的世界后果；伤害、制服及战斗比重仍待设计与试玩。

    “不惊动他人”暂建议作为任务质量目标：取回道具并成功撤离是基本完成条件；完全未被发现是更高评价。被发现后允许躲藏、绕路或回退，避免一次失误立即重开。此项为设计建议，尚未接入评价系统。

    当前已记录的运行合同¶

    本节依据当前 README 和 3C Playground，描述已有制作基线，不表示新剧本已接入。

    • 默认入口 scenes/main.tscn，当前仍是连续世界测试场；独立 3C 测试入口为 scenes/3cplayground.tscn。
    • 第三人称背后越肩透视镜头；鼠标自由观察、右键拉近、V 换肩、中键回正、滚轮调距离。Esc 释放鼠标，点击场景恢复控制。
    • WASD 相机相对移动、Shift 跑步、空格跳跃、F 主动交互。
    • Q/E 单按回退/快进一秒，长按连续浏览已记录历史；结束后暂停，T 继续。E 不生成尚未发生的未来。
    • 暂停且存在后续录像时，R 将后续录像固定成分身。允许回到分身生成前，已有录像不被改写；录像播放一次后停留于终点。
    • 分身受真实障碍物和交互条件约束；没有旧版行动能量、驻影/循环分身操作与复杂时间线 HUD。
    • 当前 HUD 仅有暂停按钮。机关交互会记录并回放；分身录像不进入长期存档。
    • 时间快照与长期世界进度分开；具体历史窗口、阻挡行为及接口以 3C 合同为准。

    制作与表现基线¶

    关卡源在 scenes/level_editor/，机关源在 scenes/mechanisms/，敌人定义在 resources/enemies/。三套节点编辑器配合三维视口进行手工制作，HUD 使用原生可编辑场景。保留用户制作的资源。

    当前默认世界使用晴日微缩光照 V2，白模空岛光照 V1 独立保留；白盒采用米制网格。新剧本不要求立即替换已有美术或重做用户场景。

    工具与模块接口以 共同规范、关卡接口、机关接口、敌人接口 为准。

    首轮白盒建议¶

    按最新关卡构想，建议先制作剧院的小片段，验证维修伪装、票券、翻窗、强闯四种入口，以及高潮取物、气泡交互与安保升级。具体研究依据及验收点见 潜行与社会互动调研。此前的 钟楼白盒方案 保留为旧候选，供参考分身机关与撤离思路。

    当前尚未提供任务中枢、跨时间线任务切换、异物识别/携带/封存、撤离结算及新剧情内容。这些是后续实现范围，不能把现有编辑器或分身测试通过视为新任务已完成。
