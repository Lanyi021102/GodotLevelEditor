    编辑器功能地图¶

    先按你要制作的内容找到入口，再进入对应指南。下列名称以 2026-11-16 的项目界面和模块说明为依据。

    入口在哪里¶

    我要制作 使用入口 用来做什么 继续阅读
    地形、建筑、通道、白盒物件 Godot 原生 3D 视口 通过轮盘添加物件，编辑位置、旋转、尺寸及点线面 关卡操作
    完整关卡 独立窗口：关卡 → 我的关卡 新建、选择、命名关卡，设置天空预设 快速开始
    整关始终有效的逻辑 关卡 → 关卡编辑 常驻触发、机关联动、NPC 互动与接取任务 常驻关卡图说明
    可复用机关组合 机关 → 我的机关 → 机关编辑 组合组件、绑定对象、设置状态、连线及预览 按钮开门案例
    事件及有先后顺序的目标 任务 → 事件与任务 / 任务图 创建事件和任务、绑定关卡、编排触发和完成条件 套件说明
    对话与角色台词 台本 管理对话组、Comments、对白和角色 台本说明
    NPC 状态机 NPC → 我的NPC → 编辑页 编辑敌人／NPC 定义与状态转换 NPC / 敌人说明
    天空、太阳、雾与曝光 天空 编辑和另存预设，预览后绑定到关卡 天空说明
    HUD 排版与样式 Godot 原生 2D 视口 编辑 scenes/hud.tscn 和 HUD 主题 HUD 说明
    基础角色操作和镜头 打开 scenes/3cplayground.tscn 后 F6 检查移动、跑跳、镜头及交互 3C 测试说明

    三类逻辑如何分工¶

    逻辑 何时运行 适合放什么
    机关图 机关实例在运行且启用时 按钮控制门、压力板组合、终端控制升降台
    常驻关卡图 关卡运行时，不依赖接取任务 与常驻 NPC 对话、触发环境机关、接取事件首项任务
    任务图 事件已接取／启动，且它是当前关卡的当前任务时 等待目标到位、更新子目标、完成或失败任务

    例如，按钮开门可以直接写在机关图里；“门完全打开后完成当前任务”写在任务图里。两者可以读取同一扇门的真实状态。

    素材与实例如何分工¶

    在“我的机关”编辑的是可复用素材。把素材放进关卡后，场景里的每一份是一个实例。实例的位置和任务归属在当前关卡中保存，修改源素材则可能影响所有使用它的关卡。

    准备制作自己的机关版本时，先在机关编辑页 另存为；放置时选择新版本。见 按钮开门教程。

    常驻对象与任务对象¶

    轮盘添加 NPC、Room 和机关时，先选择 关卡常驻 或 任务对象。

    • 关卡常驻：随关卡存在，适合门、区域检测和负责接取任务的 NPC。
    • 任务对象：绑定本关的一个任务，只在任务 active 时显示和启用。未激活、完成或失败后关闭显示、处理与碰撞。

    NPC 阵营目前用于实例配置与占位颜色；默认动作会播放模型中已有的匹配动画。完整阵营战斗、巡逻路径执行及行为引用接入仍有边界，详见 轮盘实例说明。

    如何读旧专项文档¶

    本 Wiki 的操作指南按当前工作流整理。模块原有 README、INTERFACES 和验证记录继续保留，页面顶部会提示其包含专项或阶段资料。

    如果同一旧页面既写了 CSV 又写了 XLSX，或同时出现旧入口和新入口，先看最新覆盖说明。当前任务与台本数据使用 XLSX，当前箱庭关卡不需要房间接驳图，时间线与分身玩法已删除。

    需要继续开发时，从 开发维护索引 查到模块负责人文件、接口和验证入口。
