    快速开始¶

    完成本页后，你会有一个自己创建、可以保存并用 F6 试玩的白盒关卡。若只想先体验机关，直接跳到 按钮开门案例。

    1. 打开项目¶

    1. 准备 Godot 4.7.1，在项目管理器导入工程根目录的 project.godot。
    2. 首次打开等待资源导入完成。macOS 也可双击工程根目录的 启动项目.command。
    3. 点击顶部 GodotLevelEditor，或使用 项目 → 工具 → 打开 GodotLevelEditor，打开独立编辑窗口。

    两个窗口配合使用

    原生 3D 视口负责摆放空间，独立窗口负责逻辑和数据。独立窗口中没有第二份三维视口；切回 Godot 主窗口就能继续摆放。

    找不到入口时，查看 编辑器入口不见了。

    2. 创建自己的关卡¶

    1. 在独立窗口点击 关卡 → 我的关卡。
    2. 点击 新建关卡 卡片。
    3. “关卡名”填一个未被使用的程序名，例如 wiki_first_level；“关卡中文名”填 我的第一个关卡。
    4. 保持默认天空预设并确认。编辑器会创建关卡场景、分配关卡 ID，并打开编辑。

    关卡名使用字母、数字和下划线，以字母开头，避免空格与标点。关卡中文名用于界面显示。

    预期结果：原生场景页打开一个带基准地面、玩家出生点及光照的新关卡；独立窗口进入“关卡编辑”，显示整关常驻逻辑图。新关卡不需要设置房间接驳线。

    3. 摆放第一个白盒¶

    1. 回到 Godot 主窗口，切换到当前关卡的 3D 视口。
    2. 点击工具栏 呼出轮盘，或短按反引号键（通常在 Esc 下方）／鼠标侧键。
    3. 在轮盘中选择 Layout 白盒，移动鼠标到地面，左键放置一个物件。
    4. 右键或 Esc 结束放置。选中物件，使用原生移动、旋转和缩放工具调整。
    5. 如需改变放置精度，在工具栏步长输入框填写数值，或选择 0.1 / 0.5 / 1 预设，单位为米。

    新增白盒会归入场景根下的 Whitebox 分类节点。不要把分类节点当作可复用素材；它用于组织当前场景。

    更多放置、旋转、常驻与任务对象选择见 关卡与轮盘操作。

    4. 检查出生点并保存¶

    找到场景中的玩家出生点，确认它位于可站立的地面上方，附近没有封闭的碰撞体。轮盘选择玩家出生点时，已有的标记会移动，不会继续新增同类玩家标记。

    使用 Godot 保存场景；也可在独立窗口“关卡编辑”点击 保存场景。若同时改了任务、台本等数据，使用独立窗口右上角 … → 保存全部。

    5. 按 F6 试玩当前关卡¶

    确认当前活动场景是刚创建的大世界关卡，再按 F6。运行时会自动接入基础角色、第三人称镜头、HUD 和当前关卡的常驻逻辑服务，无需手动把角色放进场景。

    操作 按键
    移动 / 跑步 WASD / Shift
    跳跃 / 互动 空格 / F
    镜头转动 鼠标移动
    释放鼠标 / 恢复控制 Esc / 点击游戏画面
    停止试玩 使用 Godot 的停止运行按钮

    预期结果：角色从本关出生点出现，可以移动、跑步与跳跃；掉出关卡后自动复位。试玩期间独立编辑窗口保持原有打开状态。

    F5 和 F6 的区别

    F5 运行项目主入口，目前是默认空白工作区。F6 运行当前场景；测试新关卡时请使用 F6。普通素材场景不一定具备关卡试玩所需的地面和角色环境。

    检查是否完成¶

    • “我的关卡”中能找到自己的关卡。
    • 关闭并重新打开场景后，白盒的位置仍然保留。
    • F6 从正确出生点生成角色，可以行走和跳跃。
    • 停止试玩后仍能继续编辑。

    下一步：把按钮开门组合放进这个关卡。
