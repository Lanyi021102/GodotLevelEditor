# Kenney vehicle models

The three models are Kenney assets under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). They are included as art assets under that license.

| File | Source and local adaptation |
|---|---|
| `kart.glb` | [Kenney Car Kit](https://kenney.nl/assets/car-kit), [pinned GLB representation](https://github.com/Papyszoo/CC0-Public-Domain-Models/blob/6eff5b79357bff6bf9b578f7a50b29d8cb42ed74/packs/kenney-car-kit/models/kart_oobi/kart_oobi.glb). Removed the decorative rider from the scene hierarchy so players can occupy the seat. |
| `motorcycle.glb`, `Textures/colormap.png` | [Kenney Starter Kit Racing](https://github.com/KenneyNL/Starter-Kit-Racing#readme), [pinned model and textures](https://github.com/KenneyNL/Starter-Kit-Racing/tree/2f2e5f2646dda89cb21d4e8539bab60c6e955dc8/models). Original asset files. |
| `speeder.glb` | [Kenney Space Kit](https://kenney.nl/assets/space-kit), [pinned GLB representation](https://github.com/lampe-games/godot-open-rts/blob/a628ad3bb6a9a903587a181a7ee3300dbf735e81/assets/models/kenney-spacekit/craft_speederA.glb). Centered the model on its scene origin. |

Rider animations use the existing Quaternius Universal Animation Library. See [animation license](../characters/quaternius_base/LICENSE_AnimationLibrary.txt).
