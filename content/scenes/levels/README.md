# 大世界关卡

打开任一关卡后可直接 F6 试玩；运行时自动接入标准角色、第三人称镜头和 HUD，使用关卡中的玩家出生点。试玩组件不保存进关卡文件。

所有可绑定任务的大世界关卡场景都放在此目录，由配表/levels.xlsx 管理固定关卡 ID、名称和中文名。房间、机关、NPC 是关卡中的常驻内容或可复用素材。新建关卡请使用 GodotLevelEditor → 关卡 → 新建关卡。

一个关卡就是一个完整箱庭，不按房间接驳图拼接。建筑、道路、室内外空间直接在同一个 3D 场景中搭建；Room 用于关卡内区域检测，新增区域不要求连线或指定起始房间。

“黄昏山居”：打开 `dusk_mountain_house.tscn` 后 F6，含 NPC 接取、两组路敌、后院升降机、二层宝箱与钥匙开正门的八阶段任务。制作与节点说明见 [关卡文档](../../docs/levels/dusk_mountain_2026-11-16/README.md)。
